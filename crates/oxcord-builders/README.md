**Type-Safe Builders & Components V2** — Fluent, compile-time verified builders for Discord messages, embeds, modals, polls, and Components V2.

Part of the [**OXCORD**](../../README.md) multi-crate ecosystem.

---

## Features

- **Fluent API**: Builder pattern for clean, readable message constructions.
- **Components V2 Builders**: `CreateContainer`, `CreateSection`, `CreateTextDisplay`, `CreateMediaGallery`.
- **Interactive Builders**: Buttons, Select Menus, Modals, Polls, and Allowed Mentions.

## Usage

```toml
[dependencies]
oxcord-builders = "0.0.1"
```
